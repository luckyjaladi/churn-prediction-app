# Customer Churn Prediction

## Overview

Machine learning-based system to predict customer churn using XGBoost, with a deployed Streamlit web app.

## Features

* Predicts churn in real-time
* Identifies key drivers of churn
* Interactive UI using Streamlit

## Tech Stack

* Python
* Pandas
* Scikit-learn
* XGBoost
* Streamlit

## Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Key Insights

* Contract type is the strongest churn factor
* High monthly charges increase churn risk
* Low tenure users churn more
